## Needs an owner decision

1. **Proration.** A lease starting 10/27 is billed the full month. Prorate the first month?
2. **Renewal deposit.** Renewing copies the deposit, so $1,000 shows "Held" on both leases. Carry it over instead?
3. **Refund while rent is owed.** Settling refunded $849.25 while $1,000 rent was unpaid, with no prompt. Warn, or suggest an "unpaid rent" deduction?
4. **Receipt numbers.** One counter across all companies: a new company's first receipt is REC-00088. Per-company numbering?
5. **Renewal checklist.** A renewal shows the move-in rekey checklist; rekeying is for a new tenant. Hide it on renewals?
6. **Future lease reads "Active"** a year before it starts (billing is correct, by date).
